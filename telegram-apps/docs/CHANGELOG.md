# Changelog

Все заметные изменения этого проекта будут зафиксированы в этом файле.

## [2026-07-16] - OCR в Telegram Mini App

### Добавлено

- Карточка и отдельный экран OCR в главной панели приложения.
- Состояние OCR-сервиса, последнего пакетного запуска и итоговые счётчики.
- Безопасный запуск существующего n8n OCR-workflow с подтверждением и
  автоматическим обновлением состояния.
- Серверная проверка подписи и срока жизни Telegram Mini App `initData`.
- Runtime-передача Telegram/OCR секретов без хранения значений в исходниках.

### Безопасность

- Анонимный браузер и подделанный Telegram user ID не могут читать OCR-статус
  или запускать ресурсоёмкую обработку.

## [2026-07-13] - Команда пакетного OCR

### Добавлено

- Команда `/ocr` для владельца бота.
- Немедленное подтверждение при передаче команды в n8n.
- Защита от запуска команды посторонним пользователем и от неверного синтаксиса.
- Итоговый Telegram-отчёт формируется OCR workflow после завершения batch.

## [2026-04-08] - Улучшение обработки ошибок сохранения
### Исправлено
- Реализована детальная обработка ошибок в методе `save()` на фронтенде.
- Добавлено логирование ответов API и ошибок сети для облегчения диагностики в TMA.
